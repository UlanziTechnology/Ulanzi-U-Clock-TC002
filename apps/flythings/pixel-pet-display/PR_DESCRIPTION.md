## Summary

新增 `pixel-pet-display`，这是一个运行在 TC002 上的 FlyThings 原生互动像素宠物应用。

## 功能

- 支持小猫、小狗、兔子三个宠物
- 旋钮旋转切换当前宠物
- 左键触发走路
- 中键触发开心
- 右键短按触发吃饭
- 右键长按触发睡觉
- 喂食动画会先让宠物走到饭碗边，再让食物消失
