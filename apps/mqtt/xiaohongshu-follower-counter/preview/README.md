# 预览与真机证据

`demo.png` 是 Bridge 渲染器生成的 52×16 **渲染预览**，用于检查像素尺寸、文字布局和 PNG 编码；它不是真机照片，也不能替代上游贡献指南要求的真实 TC002 运行截图。

正式提交 PR 前，由设备持有人补充以下任一文件：

- `tc002-real.jpg`：能清楚看到 TC002 机身和粉丝数画面；
- `tc002-real.gif`：能看到 MQTT 更新前后的真实设备画面。

素材不得包含 MQTT 密码、共享令牌、个人浏览器页面或其他隐私信息。加入真机素材后，应在应用 README 和 `docs/PR.md` 中引用，并勾选“已附运行截图或视频”。
